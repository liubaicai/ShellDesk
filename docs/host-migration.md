# 主机迁移

ShellDesk 主机页工具栏中的“迁移主机”向导用于从其他 SSH 客户端或表格清单导入主机。向导先读取和预览文件，只有用户确认后才写入 Vault；读取文件本身不会修改现有主机。

## 支持格式

| 来源 | 常见文件 | 迁移内容 |
| --- | --- | --- |
| MobaXterm | `MobaXterm.ini`、书签 INI | 名称、地址、端口、用户名、书签分组 |
| Xshell | `.xsh` | 名称、地址、端口、用户名、密钥路径、父目录分组 |
| SecureCRT | 会话 `.ini`、多会话 `.xml` | 名称、地址、端口、用户名、父目录分组 |
| CSV | `.csv` | 名称、地址、端口、用户名、分组、标签、备注、密钥路径和可选密码 |

CSV 首行是列名，列名不区分大小写。常用别名包括 `name/session/title`、`host/hostname/address/ip`、`user/username/login`、`group/folder/category`、`tags/labels`。标签可用分号、竖线或逗号分隔。

文件选择器一次最多读取 500 个文件，每个文件最多 2 MiB、总计最多 20 MiB；预览最多包含 5000 台主机。支持 UTF-8、UTF-8 BOM，以及带 BOM 的 UTF-16 LE/BE。选择器只把文件名、父目录名和内容交给前端，不暴露完整本地路径。

## 预览、去重与应用

预览会逐项校验地址和端口。空用户名默认设为 `root` 并显示警告；无效项不能选择，但不会阻止其他有效主机导入。预览列表采用固定行高虚拟化，搜索和滚动不会一次渲染全部候选项。

重复项按规范化后的“地址 + 端口 + 用户名”识别，包括现有 Vault 主机之间的冲突和本批文件内部的冲突。应用时可选择：

- 跳过重复项：保留现有主机。
- 用导入配置替换：保留现有主机 ID、创建时间、最近连接状态和已识别系统信息，替换可迁移配置。
- 保留两者并重命名：添加新主机，并为重名项生成不冲突的名称。

每次成功应用会在当前进程中保存一个撤销快照。只有当前主机集合仍与刚导入后的结果完全一致时才能撤销；如果导入后又编辑、添加或删除了主机，撤销会安全拒绝，避免覆盖后续修改。

## 凭据边界

- MobaXterm、Xshell 或 SecureCRT 自身加密的密码不会迁移，因为 ShellDesk 无法安全复用其他客户端的加密上下文。
- CSV 中的明文密码默认不导入。预览会明确显示数量，只有勾选授权后才随主机写入 Vault。
- 导入的主机默认启用 keepalive，并沿用 ShellDesk 的主机密钥校验、凭据保护和连接流程。

建议在导入后抽查分组、用户名、端口和认证方式，再删除原始导出文件。包含明文密码的 CSV 应只保存在可信位置，并在迁移完成后按组织策略安全处理。

## 验证

纯解析和导入计划由 `tests/unit/host-import.spec.ts` 覆盖；原生选择器的 UTF-8/UTF-16 解码由 Rust 单元测试覆盖；Playwright UI 冒烟覆盖文件选择、重复项预览、替换策略和结果摘要。真实第三方客户端版本可能产生新的字段变体，无法识别的格式会作为文件错误显示而不会写入 Vault。
